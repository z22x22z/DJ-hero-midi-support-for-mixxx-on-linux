What each button does
Circle / X / Square / TriangleHot cue 1 / 2 / 3 / 4 on the hot cue deck. Hold one for a moment and it turns sticky: it stays held after you let go, and pressing it again releases it.
PS (tap)Switch which deck the hot cue buttons control (the active deck is not changed).
PS (hold) + X / Circle / SquareX: 4-beat loop on, press again to turn it off. Circle: loop in. Square: loop out. These act on the active deck.
Platter red / green / blueRed: sync lock. Green: cue (hold to preview). Blue: headphone cue. All on the active deck.
PlatterScratches the active deck.
EuphoriaNext effect in the list: Filter deck 1, Filter deck 2, Echo, Phaser, Reverb. The knob adjusts the selected one.
D-pad up / downTempo up / down (hold to repeat).
D-pad rightSwitch the active deck, 1 and 2.
D-pad leftEffect on / off (a filter acts on its own deck, the others on the active deck).
Select / StartPlay / pause deck 1 / deck 2.
